## Causa do erro de alinhamento

A única geração aceita nesta retomada falhou com código 2. Novo relatório:
**`541028f13315`**, schema 2, operação **`load_model`**.

Cadeia observada: `ValueError` em `whisperx.alignment:106`, envolvendo `OSError`
em `transformers.models.wav2vec2.processing_wav2vec2:70/59`, com `IndexError`
interno. Os três relatórios anteriores não retiveram informação suficiente
para provar retroativamente a mesma causa.

A configuração portátil em `app/core/config.py` define `XDG_CACHE_HOME` para
o cache do aplicativo. Hugging Face usa essa variável para construir o cache
implícito. O modelo PT existente está em `~/.cache/huggingface/hub`, não no cache
portátil. Com o ambiente efetivo, WhisperX não encontra o feature extractor
`preprocessor_config.json` e encapsula a falha em um `ValueError` genérico.
Uma reprodução sem áudio produziu os mesmos fingerprints das exceções do
relatório. Com o cache existente explicitado, o modelo carrega offline.

Correção: resolver o cache PT completo antes do reconhecimento e passar sua
localização ao subprocesso via `HF_HUB_CACHE`. O cache efetivo completo tem
precedência; configurações explícitas de Transformers/Hugging Face são
respeitadas. Sem modelo completo, falhar antes de executar ASR. Nenhum peso foi
copiado, movido, instalado ou baixado.

Torch `2.8.0+cpu` e Torchaudio `2.8.0+cpu` correspondem entre si; Transformers
`4.57.6` atende ao requisito `>=4.48.0` da instalação WhisperX `3.8.6`.
O carregamento real e uma inferência sobre zeros produziram logits finitos
`[1, 49, 46]`. Isso verifica carregamento/compatibilidade, não precisão musical.
Referências primárias: [TorchAudio](https://docs.pytorch.org/audio/stable/installation.html)
e [WhisperX 3.8.6](https://pypi.org/project/whisperx/3.8.6/).

O worker mantém Vulkan GPU 0 para ASR e CPU para WhisperX. Não foram alterados
timeouts ou dependências. `[3/4]` é alinhamento; `[4/4]` é diarização desativada.
O diagnóstico persiste apenas classes, categorias, operação, módulo/linha
permitidos, versões e fingerprints; não persiste mensagens brutas, caminhos,
áudio ou letras. A cadeia atravessa exceções encapsuladas.
